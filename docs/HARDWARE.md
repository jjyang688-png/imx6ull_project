# 硬件资源规划

## 1. 开发板信息

| 项目 | 值 |
|------|------|
| SoC | NXP i.MX6ULL (ARM Cortex-A7, 792MHz) |
| 开发板 | 正点原子 ALPHA i.MX6ULL |
| 内核 | Linux 4.1.15 (正点原子 BSP) |
| 调试串口 | UART1 (Micro USB, CH340) |

## 2. 外设资源汇总

### 2.1 已有外设 (v1.0)

| 外设 | 接口 | 引脚/地址 | 中断号 | 备注 |
|------|------|------|------|------|
| LED | GPIO | GPIO1_IO03 | — | 低电平有效 |
| KEY0 | GPIO + IRQ | GPIO1_IO18 | 双边沿触发 | 低电平有效, 去抖 20ms |
| AP3216C | I2C1 | 0x1E | — | 光照+红外+接近, 100kHz |
| ICM20608 | ECSPI3 CS0 | `reg = <0>` | — | 6轴传感器, SPI Mode 0, 8MHz |
| UART3 | UART 裸寄存器 | 基地址 0x021EC000 | GIC_SPI 28 | DB9 RS232, 115200-8-N-1 |

### 2.2 新增外设 (v2.0)

| 外设 | 接口 | 引脚 | 中断号 | 备注 |

### 5.3 UART 配置

| 参数 | 值 |
|------|------|

### 5.4 DHT11 单总线时序

| 参数 | 值 |
|------|------|
| 起始信号拉低 | ≥ 18ms |
| 起始信号拉高 | 20~40μs |

| DHT11 响应高电平 | 80μs |
| bit 0 高电平 | 26~28μs |
| bit 1 高电平 | 70μs |

|------|------|

| 距离公式 | distance(cm) = pulse_width(μs) / 58 |
| 量程 | 2cm ~ 400cm |
| 测量周期 | ≥ 60ms |

### 5.6 舵机 PWM 参数

| 参数 | 值 |
|------|------|

| 180° 占空比 | 2.5ms (12.5%) |
| 角度→脉宽公式 | pulse_us = 500 + angle × 2000 / 180 |

## 6. 电源需求

| 外设 | 电压 | 最大电流 | 备注 |
|------|------|------|------|
| DHT11 | 3.3V | 2.5mA | 板载 3.3V 供电 |
| SR04 | 5V | 15mA | 板载 5V 供电 |
| MQ135 | 5V | 150mA | 加热器功耗大, 建议外接电源 |
| 舵机 | 5V | 500~1000mA | 峰值电流大, 必须外接电源 |
| 继电器 | 5V | 70mA | 板载 5V 供电 |
| CAN 收发器 | 3.3V | 10mA | 板载 3.3V 供电 |
